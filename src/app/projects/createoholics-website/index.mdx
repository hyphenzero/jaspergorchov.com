Create-O-Holics is a creative fabrication studio that builds custom props, sets, and experiential installations for brands and agencies. They needed a website that could do justice to their portfolio — high-resolution photography, project case studies, and a clean browsing experience that put the work front and center.

## Design goals

The brief was straightforward: let the work speak. The design uses generous whitespace, a muted typographic palette, and full-bleed imagery to create a gallery-like feel. Each project page opens with a hero image that spans the full viewport, followed by a detail grid that breaks down the materials, process, and client story behind each build.

The navigation is minimal — a single-tier menu with a focus on the portfolio categories. We wanted visitors to go from landing page to project gallery in two clicks or fewer.

## Technical implementation

The site is built on WordPress with a custom theme, which gives the client full control over their content without needing to touch code. The portfolio uses a custom post type with advanced custom fields for materials, dimensions, client logos, and process photos. The gallery component supports both grid and masonry layouts, with lightbox viewing for full-resolution images.

Performance was a priority — the image-heavy nature of the site meant we needed careful lazy-loading, responsive image sizes, and a CDN for the asset delivery. The final Lighthouse scores came in well above 90 across all categories.

## Takeaway

This project reinforced the importance of listening to what a client's work actually needs from a website. The most successful design decisions weren't about adding visual flair — they were about removing barriers between the visitor and the portfolio.
