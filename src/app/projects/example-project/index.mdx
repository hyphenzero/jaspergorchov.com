# Interactive Site Redesign

This demo project shows how you can mix regular markdown content with the custom MDX components for project pages.

Below is a responsive image grid. The grid supports 1-4 columns via the `columns` prop — pass the number you want for large screens.

<ImageGrid>
  <Image src={image} alt="Screenshot 1" />
  <Image src={image} alt="Screenshot 2" />
  <Image src={image} alt="Screenshot 3" />
  <Image src={image} alt="Screenshot 4" />
</ImageGrid>

You can also include a single image using normal markdown or the project's `Image` component:

<Image src={image} alt="Hero screenshot" />
